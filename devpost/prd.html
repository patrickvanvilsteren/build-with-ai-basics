Behaviors and how we check them

Run on demand
  • One run does one full check, then ends.
  • No automatic schedule exists.
Finding events (next 7 days)
  • Only events starting within 7 days of the run are considered.
  • Later events are not listed or added.
Skipping events already in Outlook
  • Same name and date/time: not listed, not created again.
  • Same name, different date/time: new.
  • Running twice in a row creates no duplicates.
Creating tentative Outlook items
  • Marked tentative.
  • Has title, date, time, description, and location where Discord provides them.
  • You can accept or decline it in Outlook.
Result list
  • Lists each new event (name and date/time at minimum).
  • Skipped events are not shown.

Now vs. later

Building now
  • Manual run
  • Discord events, next 7 days
  • Duplicate check (name + date/time)
  • Tentative Outlook items
  • Result list and two messages
Deferred
  • Daily 20:00 run — can't be shown in a short demo
  • Looking further than 7 days
  • WhatsApp, email, more servers, conflict handling
