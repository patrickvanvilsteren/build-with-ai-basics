Wild Wolves Agenda Bridge

A personal agenda assistant that turns scheduled events from the Wild Wolves Discord server into tentative Outlook calendar events.

The kernel

The assistant watches one specific Discord server's event scheduler instead of trying to understand every message. It turns an event that matters into a tentative Outlook item that the learner can accept or decline.

The proof is not a new calendar. It is the reliable handoff between a community event and the learner's personal agenda.

What working looks like

A scheduled event is found in Wild Wolves and appears in Outlook with a useful title, date, time, and relevant context. The learner opens the tentative item and accepts or declines it. Discord scheduled events always provide the date and time needed for the Outlook item.

Boundary

Now

  • Read scheduled events from Wild Wolves only.
  • Use title, date, time, description, and location.
  • Create a tentative Outlook event for review.
  • Demonstrate accepting or declining it.

Later

  • WhatsApp scanning and replies.
  • Email invitation handling.
  • Additional Discord servers.
  • Conflict handling, reminders, and recurring events.

Cut for this proof

  • Ordinary Discord message scanning.
  • A polished standalone dashboard.
  • Multiple sources before the central loop works.

Why it matters

This project addresses the learner's need for better control of a busy agenda while practicing basic Python, understanding how an AI coding assistant works, and learning to turn a real problem into a small, testable program.
